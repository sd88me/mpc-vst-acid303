# Fonts

The Acid plugin's faces (mpc-vst-acid `vst/fonts/`), so the two plugins match:

- `Univers_53_Extended_Regular.otf`: the panel lettering and labels. Univers is a Linotype typeface.
- `Earth_Normal.ttf`: the MODEL-303 wordmark only (it has no dash: the skin draws it).

Confirm both licences allow redistributing the font files (or baking them into the skin images) before a public release.
